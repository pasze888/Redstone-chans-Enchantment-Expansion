# Redstone 附魔扩展 (Redstone-chans Enchantment Expansion)

[English](README.md) | [简体中文](README.zh-CN.md)

一个 NeoForge 1.21.1 附魔扩展，新增 217 个附魔。
Fork 自 [WitherRedstone/Redstone-chans-Enchantment-Expansion](https://github.com/WitherRedstone/Redstone-chans-Enchantment-Expansion)。

## 安装

需要 **Minecraft 1.21.1** 与 **NeoForge 21.1.219** 或更高版本。

1. 为 Minecraft 1.21.1 安装 NeoForge。
2. 把模组 jar 放进 `mods/` 目录。
3. 启动游戏——无需任何配置。
